 MyStore – E-commerce Website
 Project Description
MyStore is a simple and responsive e-commerce website created using HTML, CSS, Bootstrap, and JavaScript. It displays different products with their images, names, and prices.

Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

Project Features
- Responsive navigation bar
- Product listing with 8 products
- Category filtering
- Search products by name
- Sort products by price (low to high and high to low)
- Premium label for products costing more than Rs. 4600
- No products found message when no matching product is available
- Separate product details page

Project Structure

How to Run the Project
1. Download or extract the project folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. Use the search bar, category filters, and sorting button to explore the products.
